H3 CSV Pack
============
Nova-style CSV loader columns:
index,name,prompt,negative_prompt,category,weight,favorite

Dropdown display uses 'name'. Inserted prompt text uses 'prompt'.

Included files:
- H3_Yoga_Poses.csv
- H3_Characters.csv
- H3_Clothing.csv
- H3_Hair.csv
- H3_Expressions.csv
- H3_Camera_Moves.csv
- H3_Environments.csv
- H3_Actions.csv
- H3_Lighting.csv
