NOVA KREA EDIT CHARACTER REF PACK — README FIRST

CONTENTS
- 115 concise, stackable Krea2 Edit / character-reference snippets.
- 23 numbered category folders, including separate Low, Medium, and High Edit Strength guidance.
- Master, alphabetical master, and four best-of subsets in 99_masters_and_best_of.
- CSV schema: index,name,prompt,negative_prompt,category,weight,favorite

CORE WORKFLOW
1. Start with Lock Original Identity or Reference Is Authoritative.
2. Add one preservation snippet for every element that must not change.
3. Add one requested edit or repair snippet.
4. Add the matching Low, Medium, or High Edit Strength guidance.
5. Add one or two focused Safe Negative Prompts; avoid an excessively long negative stack.
6. Index values are stable across category, master, alphabetical, and best-of files.

EDIT STRENGTH GUIDANCE
- Low: tiny cleanup, color tweak, face-adjacent edits, or minimal collateral change.
- Medium: visible garment, lighting, reframe, or anatomy correction with strong preservation anchors.
- High: major style, outfit, background, or rebuild changes; scope the region and explicitly lock identity, pose, and untouched areas.

RECOMMENDED FULL-BODY FLOOR POSE EDIT STACK
- Lock Original Identity
- Lock Body Proportions
- Lock Exact Pose
- Clarify Full Floor Pose
- Restore Head-to-Toe Frame OR Overhead Floor-Pose Reframe
- Full-Body Deep Focus
- Medium Strength Repair
- Safe Anatomy Negative + Safe Framing Negative
If the face is already correct, also add Keep Face Unchanged.

RECOMMENDED LOW-ANGLE FACE-FOCUSED EDIT STACK
- Lock Original Identity
- Preserve Facial Geometry
- Preserve Eyes
- Subtle Low-Angle Reframe
- Sharpen Face Only
- Medium Strength Reframe, or Low Strength Face Protection for a gentler change
- Safe Identity Negative
This combination is designed to protect the face from chin enlargement, eye loss, and identity drift.

CHARACTER-SHEET / MULTI-PANEL STACK
- Read Sheet as One Character
- Use Front View for Face
- One Person Across Panels
- Cross-Panel Feature Match
- No Identity Blending
- Reference Is Authoritative

NOTES
- Prompts are guidance snippets and do not directly set a software slider. Pair the named strength guidance with the nearest available Krea2 Edit control.
- Preserve only what must remain fixed; contradictory preservation and replacement snippets reduce edit clarity.
- negative_prompt values are conservative defaults; remove terms that conflict with the desired transformation.
