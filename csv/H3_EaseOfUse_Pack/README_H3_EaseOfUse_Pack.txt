H3 Ease-of-Use Pack
===================

Purpose:
This pack is curated for easy mixing and matching in MiniMax H3 / Nova-style workflows.
All CSVs use the columns:
index,name,prompt,negative_prompt,category,weight,favorite

Recommended basic formula:
1. Pick one from H3_Ready_Made_Scenes.csv OR build your own using:
   - one Environment
   - one Lighting
   - one Character / Subject role (optional, from previous pack or your own text)
   - one Clothing
   - one Hair
   - one Expression
   - one Action or one Safe Pose
   - one Safe Camera
   - 1 to 3 Stability Blocks
   - one Audio / Music option

Best easy combinations:
- Studio Orbit Display = Neutral Studio + Soft Even Studio + Simple Fashion Pose + 360 Orbit + Outfit Lock + Anatomy Stability + Fashion Electronic
- Yoga Showcase = Neutral Studio + Soft Even Studio + Yoga Outfit + Safe Pose + Static Locked Camera or 360 Orbit + Pose Lock + Anatomy Stability
- Luxury Lingerie Reveal = Luxury Studio + Moody Rim Light + Lingerie Set + Elegant Bun or Long Wavy Hair + Flirty Smile + Arc Right or Slow Push In + Clean Visuals + Outfit Lock
- Portrait Push In = Modern Apartment or Neutral Studio + Window Light + Soft Smile + Stand and Breathe (from previous pack) + Slow Push In + Identity Lock
- Sports Intro = Basketball Court + Cool Overcast or High-Key Commercial + Basketball Uniform + Determined + Tracking Forward + Clean Visuals

Practical tips:
- For difficult shots, use fewer moving parts.
- One main action + one camera move works best.
- Use Pose Lock / Outfit Lock / Identity Lock when H3 drifts.
- For continuation clips, always add Handoff Stability.
- Standing poses are safer than floor poses or inversions.
